ABF - Modern Burka Fashion (static, responsive HTML/CSS/JS)
Open index.html in a browser (no build step, no framework).
Pages: index.html (home), product.html?id=1..6 (details + similar products), checkout.html (order form).
Edit products/prices: assets/js/app.js (array P) and the cards in index.html.
Order: no backend - the checkout validates the form and opens a prefilled WhatsApp message (number WA in app.js).
Images: assets/img (p1..p6 sample photos, logo.jpg). Prices are SAMPLE values.
